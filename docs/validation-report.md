La prueba de integración es no destructiva: consulta únicamente rutas públicas, no crea registros ni modifica la base de datos. Las alertas operativas son best-effort y no bloquean callbacks. El rate limiting local no sustituye un límite distribuido del gateway en Autoscale.

La auditoría de accesibilidad estática está documentada en `docs/accessibility-audit.md`, pero no se declara conformidad WCAG 2.1 AA completa sin una pasada manual por teclado, lector de pantalla y medición exhaustiva de contraste por estado. El filtro Gmail `label:clientes is:unread` se verificó sin resultados; el endpoint de ingestión queda preparado, pero no se inventan mensajes ni se crea ningún draft cuando el filtro está vacío. La activación productiva de jobs requiere conexiones externas y sigue documentada como pendiente.
