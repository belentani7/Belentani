# Revisión visual: variante negro y gris piedra

Fecha de revisión: 2026-08-15.

La vista pública se abrió en el navegador contra el servidor de desarrollo. En el primer viewport se observa un fondo negro dominante, superficies grafito/gris oscuro, tipografía clara y geometría circular muy tenue. No se observan acentos azules visibles en la navegación, hero ni tarjetas principales. El fondo conserva una atmósfera sobria y el contenido permanece estable; la deriva lenta está implementada como capa ambiental no interactiva mediante `transform` y queda desactivada con `prefers-reduced-motion: reduce`.

La revisión no modifica textos, rutas, orden de bloques ni controles. El contraste visual del hero y las tarjetas es legible en el viewport revisado. La comprobación completa de contraste WCAG por ruta y estado interactivo sigue siendo una tarea separada del backlog.
