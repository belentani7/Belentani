# Matriz de evidencia de seguridad

| Subrequisito          | Implementación concreta                                                                                                             | Prueba o evidencia                                                                                     | Alcance y límite                                                                                                          |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------- |
| Validación de entrada | Esquemas Zod en procedimientos tRPC, límites del agente y validación de metadatos multimedia                                        | `server/agent.test.ts`, `server/catalogIngestion.test.ts`, `server/securityMiddleware.test.ts`         | Las rutas nuevas deben seguir el mismo patrón                                                                             |
| Validación de salida  | `agentResponseSchema` valida categoría, respuesta y revisión humana antes de aceptar la salida del modelo                           | `server/agent.test.ts`                                                                                 | Aplica a salida estructurada del agente; no convierte todos los datos de DB en DTOs independientes                        |
| Mínimo privilegio     | Procedimientos administrativos protegidos por rol; lectura privada encapsulada en `server/privateData.ts`; subida restringida       | `server/platform.contract.test.ts`, `server/security-observability.test.ts`, `docs/data-boundaries.md` | La identidad final depende del proveedor OAuth y del rol persistido                                                       |
| CSRF                  | Cookie `noiacore_csrf` + header `X-CSRF-Token` para solicitudes de navegador, además de validación de Origin/Referer/Sec-Fetch-Site | `server/securityMiddleware.ts`, `server/securityMiddleware.test.ts`                                    | Las integraciones server-to-server sin señales de navegador no requieren token; deben autenticarse por su propio contrato |
| XSS                   | Renderizado React escapado y no uso de `dangerouslySetInnerHTML` en las superficies editoriales                                     | Inspección de `client/src`; búsqueda reproducible de `dangerouslySetInnerHTML`                         | Contenido externo debe continuar tratándose como texto                                                                    |
| SQLi                  | Consultas Drizzle parametrizadas y filtros tipados                                                                                  | Revisión de `server/db.ts`, `server/routers.ts` y `server/*test.ts`                                    | No interpolar SQL en futuras migraciones                                                                                  |
| Rate limiting         | Buckets temporales separados para mutaciones y multimedia con `Retry-After`                                                         | `server/securityMiddleware.test.ts`                                                                    | En Autoscale es best-effort local; para ataques distribuidos se requiere límite del gateway/proveedor                     |
| Secretos              | Variables de entorno, documentación sin valores y logging sin cuerpos sensibles                                                     | `docs/secrets.md`, `docs/data-boundaries.md`                                                           | No se debe pegar ningún token en el repositorio o chat                                                                    |

La matriz distingue **control implementado** de **garantía operativa externa**. En particular, el rate limiting distribuido y la validación formal de conformidad WCAG no deben darse por resueltos únicamente por código local.
